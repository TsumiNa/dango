## Memo
This skill is feasible if the upstream cleaned groundwater observations are already enriched with the required fields:

- `latitude`
- `longitude`
- `elevation_m`
- `water_level_m_bgl`

The canonical execution for this skill is to run `scripts/train.py`, which fits a `scikit-learn` `GaussianProcessRegressor` using an `RBF + WhiteKernel`, writes prediction results to CSV, and writes a surface plot to SVG via `matplotlib`.

PDF output is out of scope unless the user explicitly asks for it.

If `elevation_m` is missing upstream, add an upstream elevation-enrichment step before execution.
