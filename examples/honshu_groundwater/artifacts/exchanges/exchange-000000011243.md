If `elevation_m` is missing, **stop rather than training** and recommend an upstream elevation enrichment step.

## Handoff
Proceed with this skill only if the upstream enriched groundwater observation artifact contains `latitude`, `longitude`, `elevation_m`, and `water_level_m_bgl`.

Revised execution approach for orchestrator review:

1. Validate that the upstream artifact includes:
   - `latitude`
   - `longitude`
   - `elevation_m`
   - `water_level_m_bgl`

2. If `elevation_m` is missing, do **not** train.
   - Stop the workflow for this skill.
   - Request an upstream elevation enrichment step before retrying.

3. If all required fields are present, use the upstream exchange markdown artifact **verbatim** as input to the canonical training path.

4. Run `scripts/train.py`, which:
   - fits a `scikit-learn` `GaussianProcessRegressor`
   - uses an `RBF + WhiteKernel`
   - trains on `water_level_m_bgl` as the target
   - uses spatial coordinates plus `elevation_m` as predictors
   - generates Honshu-wide prediction outputs suitable for later lookup/interpolation
   - saves prediction results to CSV
   - saves a prediction surface plot to SVG via `matplotlib`

5. Expected output artifacts should support downstream spatial analysis and include at least:
   - `latitude`
   - `longitude`
   - `predicted_water_level_m_bgl`
   - uncertainty, if available from the model output

6. Do not plan or request PDF generation unless the user explicitly asks for it.
