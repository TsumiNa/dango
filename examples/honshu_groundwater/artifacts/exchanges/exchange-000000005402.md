## Reasoning
The planner draft is too vague and misframes the work as “analyze the data and generate the report.” This skill is appropriate because the requested task is structured observation parsing and elevation enrichment, not report generation. Feasible execution depends on passing the exact messy JSON payload as input; `scripts/enrich.py` is already intended to parse mixed schemas, flatten usable observations, normalize groundwater level fields, and call the deterministic in-skill elevation API shim for each usable coordinate. The downstream handoff should therefore be compact structured JSON, not a report.
